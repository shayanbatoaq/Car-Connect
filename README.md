# Safe Safar / Car Connect

A privacy-focused vehicle communication product concept built to let members of the public contact a vehicle owner through a unique QR identifier without publicly exposing the owner's personal contact information.

This repository demonstrates the product interface and implemented web flows. Planned backend or operational functionality is described as planned rather than presented as already deployed.

## Product idea

A QR sticker can act as a public identifier for a vehicle. Scanning it opens a controlled digital profile/communication experience, allowing useful contact around a vehicle while keeping private owner details out of public view.

## Implemented web experience

- Responsive product and onboarding interface
- QR-code scanning integration
- Vehicle lookup/search flows
- Dynamic vehicle/profile experiences
- Modern component-driven Next.js frontend
- Supabase client integration in the application stack

## Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS 4
- Supabase
- QR / HTML5 QR integrations
- Motion
- Material UI and Radix UI components

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

Create a production build with:

```bash
npm run build
```

## Scope

Safe Safar / Car Connect is a product concept and implementation project. Customer management, ordering, subscription management, physical QR fulfillment, and administrative operations should be treated as planned architecture unless they are explicitly implemented in the repository.
